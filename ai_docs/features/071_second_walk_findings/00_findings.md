# 071 — findings from the maintainer's second walk

Raw ledger, in the shape `069/00_findings.md` set. The maintainer walks
`ai_docs/features/068_radiance_cascades/tutorial.html` and the `## Manual verification` lists of
069's wave specs in the running app, and reports what they see; each report is recorded verbatim
with what the code actually does, so the spec that follows (`01_spec.md`) is written from verified
facts. Nothing here is fixed during the walk.

Classes: **DEFECT** (a tutorial step does not produce its stated picture), **UX** (works but
awkward), **ENGINE** (the code itself misbehaves). An ENGINE finding inside the vendored editor
carries the tag `editor lib`: per `067_custom_editor.md`, the fix lands in the editor repo
(`~/src/editor`, `alexeykarnachev/editor`) and is re-vendored here.
