tests the current working tree in the running app -- the uncommitted 070 (pass reads chips) + 072
(sampler source) diff on top of v0.28.0, plus the outstanding `## Manual verification` lists of
070, 071's waves and 072 -- and reports what they see; each report is recorded verbatim with what
the code actually does, so the spec that follows (`01_spec.md`) is written from verified facts.

**ENGINE** (the code itself misbehaves). An ENGINE finding inside the vendored editor carries the
tag `editor lib`: per `067_custom_editor.md`, the fix lands in the editor repo (`~/src/editor`,
`alexeykarnachev/editor`) and is re-vendored here.

## Decisions filed mid-walk

- **D1 (on #1). The closing-bracket snap is general: a closer typed as the first non-blank of a
  line takes the indent of the line holding its matching opener.** Maintainer: "about this
  auto-snap of the curly braces. This should also work for cases like if statement inside some
  function (basically, this should be generalized as well)". Constraint for the editor session:
  the fix is the matching-opener rule via `bracket_match`, at any nesting depth, for every
  bracket kind the pair table knows; a "column 0" or "current indent minus one step" shortcut is
  out.

- **D2 (on #4). The viewer gets a three-state channel view, off by default: Color (today's
  look), Color+Alpha (composite over a light checker), Alpha (alpha as grayscale).** Maintainer:
  "yes, let's file A", choosing it over a backdrop picker and an eyedropper readout. Constraints
  for the spec: the default frame stays byte-identical to today, the light checker appears only
  in the opt-in state, the control is a registered command with a chord and a visible toggle on
  the viewer, and the Alpha view must not disturb the texture that feedback reads and exports
  sample.

- **D3 (on #5). The dormant-tile tint goes; a live tile is marked by a soft full fill instead.**
  Maintainer: "Let's remove this dim effect. Let's maybe try another design: let's color the active
  cards in some suitible color? Like the full color fill (some non-aggressive color)". Supersedes
  071 D2. Constraints for the spec: `STALE_TINT` is deleted and a dormant image is blitted
  untinted; every pass in the output's chain (`live`) gets a quiet accent-derived fill as the
  cell ground (`preview_cell`'s `bg_color`), dormant tiles keep the plain panel ground and the
  corner tick; the output's `ACCENT_PRIMARY` border and error red stay as they are. The exact
  fill color is tuned by eye at the display.
- **D4 (on #7). Next / previous pass are commands on `Alt+Right` / `Alt+Left`, and switching
  keeps the focus where it was.** Maintainer's words in #7. Constraints: a switch is what a tile
  click is (output pass + shader tab), walking the strip's drawn order and wrapping; the editor
  keeps focus when it had it and is not focused when it did not; both chords are registered
  `CommandSpec`s so they are rebindable and the chord-uniqueness invariant covers them.
- **D5 (on #8). The Reset button leaves the preview and joins the `New document` / `Render all`
  row.** Maintainer's words in #8. The `F6` chord and the tooltip stay.
