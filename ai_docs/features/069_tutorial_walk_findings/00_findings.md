# 069 — findings from the maintainer's walk of the 068 tutorial

Raw ledger. The maintainer walks `ai_docs/features/068_radiance_cascades/tutorial.html` and reports
concerns as they go; each is recorded here with what the code actually does, so the spec that
follows (`01_spec.md`) can be written from verified facts rather than from recollection.

Nothing here is fixed yet. Two classes, per the roadmap banner:

- **DEFECT** — a tutorial step does not produce its stated picture. Fix goes to `tutorial_body.html`
  (then re-run `build_tutorial.py`).
- **UX** — the step works but is awkward. Accumulates into the next feature's spec.

A third class, **ENGINE**, is for findings where the code itself misbehaves (not the tutorial text).

## Rule filed mid-walk

The word-budget rule for UI strings now lives in `.claude/skills/imgui-ui/SKILL.md § 2` (label 1-2
words; icon tooltip = the control's name; `help_marker` one clause <= 8 words and only where the
label is ambiguous; empty state <= 4 words; derived values in the control, never the label). The
previous wording of that section ("a control that needs a sentence gets a `?` with the sentence",
with a "16-bit float — holds values above 1" example) is what licensed #5, #7 and #10; it is gone.
A rule with no gate is a wish: the spec owes a check that measures every `set_tooltip(` /
`help_marker(` / `separator_text(` literal against the budget, shipped with the sweep that cuts them.
