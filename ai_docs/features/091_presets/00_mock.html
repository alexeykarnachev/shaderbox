Local mock, nothing here is wired. Colours and sizes follow theme.py (tile 168, thumb 112, chips under the name = what the pass reads). The panels are resizable from their bottom-right corner, so wrapping can be judged at 480 and up. Example document: a five-pass Bloom Chain imported as group bloom with prefix fx_, its scene pass substituted with the host's own scene, and a host pass final reading the bundle's output.

C2 keeps everything on one flow and pays with a second tile size, which the theme would need a token for (`PASS_TILE_GROUPED`). C3 adds no height at all; the members lose their own borders and sit 4px apart so the outline reads as one thing, and the label rides the border.

2 · The import dialog

Three shapes for the same operation: pick a source document, choose a prefix and a group name, and say for each of its passes whether it is copied or substituted with a host pass. Substitution is how an input is bound: every sampler that read the substituted pass is written to read the host pass instead.
